03
Tasarım
Veri modelleri, şablon tasarımı, YAML formatı
Nisan 2026 ▶
NK
Nehir Kökten
Proje Lideri

Raporlama modülünün HTML şablonunu tasarladım. Raporun görsel düzeni bu hafta şekillendi: koyu arka plan, renk kodlu zafiyet kartları (kırmızı=kritik, turuncu=yüksek), yönetici özeti bölümü ve CWE referans numaraları. Bunun yanında ReportGenerator sınıfının iskeletini ve metot imzalarını yazdım.

NKa
Nursena Karaduman
Backend · DB

models.py dosyasını yazdı. Severity, VulnType, ScanStatus, Vulnerability, ScanResult sınıfları bu dosyada hayata geçti. Bu modeller projenin ortak dili oldu; tüm tarayıcılar aynı Vulnerability nesnesini üretmeye başladı. Ayrıca BaseScanner soyut sınıfını ve SCANNER_REGISTRY sözlüğünü oluşturdu.

MSK
Muhammet Sefa Kozan
Backend · Test

SQLMap entegrasyon modülünün tasarımını yaptı. SQLMap'in sistemde kurulu olup olmadığını kontrol eden, varsa subprocess ile çalıştıran, yoksa kendi SQLi tarayıcımıza düşen fallback mekanizmasını tasarladı. Ayrıca URLValidator ve TargetValidator sınıflarının güvenlik gereksinimlerini kodlamaya başladı.

ŞD
Şevval Duran
Frontend · UI/UX

Web arayüzünün HTML iskeletini ve CSS değişkenlerini yazmaya başladı. Koyu tema için renk paletini ve sayfa düzenini oluşturdu. Sidebar navigasyonu ve ana içerik alanının yapısı bu haftada kodlandı.

MBB
Muhammed Baki Başbay
Backend · Docs

YAML senaryo formatını kesinleştirdi. id, info (name, severity, cwe, remediation) ve requests (method, path, matchers) alanlarından oluşan format bu hafta son halini aldı. status, word ve regex matcher türleri ile AND/OR koşul mantığı tasarlandı.

04
Geliştirme — Temel
Tüm modüller kodlandı — en yoğun hafta
Yoğun ▶
NK
Nehir Kökten
Proje Lideri

ReportGenerator sınıfını tamamladım. generate_html(), generate_json() ve generate_pdf() metodlarını yazdım. PDF üretimi için reportlab kütüphanesini entegre ettim; Türkçe karakter desteği için DejaVu Sans fontlarını projeye ekledim. Flask API sunucusunun temel endpoint'lerini (/api/scans, /api/scans/<id>/report) yazdım.

NKa
Nursena Karaduman
Backend · DB

database.py dosyasını yazdı. 5 tablolu SQLite şeması, PRAGMA foreign_keys = ON ile referans bütünlüğü, @contextmanager ile otomatik commit/rollback bu dosyada hayata geçti. Ardından en kritik tarayıcıları yazdı: sqli_scanner.py (hata tabanlı ve time-based blind SQLi), xss_scanner.py (HTML, attribute, SVG, JS bağlamları), port_scanner.py (Nmap + socket fallback, 20+ port). O haftada en fazla kod satırı yazan ekip üyesiydi.

MSK
Muhammet Sefa Kozan
Backend · Test

sqlmap_scanner.py modülünü ve orchestrator.py'yi yazdı. Orchestrator, tüm sistemi bir arada tutan koordinatör modüldü; URL normalize etme, modülleri sıraya koyma, sonuçları toplama ve veritabanına yazma akışını yönetti. cli.py arayüzünü ve requirements.txt ile setup.py dosyalarını da tamamladı.

ŞD
Şevval Duran
Frontend · UI/UX

Web arayüzünü (index.html, style.css, script.js) tamamladı. Dashboard istatistik kartları, tarama başlatma formu, tarama geçmişi tablosu ve gerçek zamanlı durum güncellemelerini yazdı. API nesnesiyle Flask endpoint'lerine bağlandı. Docker ve docker-compose.yml yapılandırmasını hazırladı.

MBB
Muhammed Baki Başbay
Backend · Docs

ScenarioScanner sınıfını yazdı. scenarios_data/ klasöründeki tüm .yaml dosyalarını otomatik yükleyen, matcher'ları çalıştıran ve Vulnerability nesnesi üreten motoru hayata geçirdi. Hatalı YAML dosyalarının sistemi çöktürmemesi için hata yönetimi ekledi.

Backend · Test

Sistemde 3 kritik bug tespit edildi ve kapatıldı. BUG-001: Türkçe karakter içeren dosya adları hata veriyordu → ASCII dönüşümüyle çözüldü. Ayrıca test_orchestrator.py yazıldı.

MBB
Muhammed Baki Başbay
Backend · Docs
